# SysNet - 轻量安全内网穿透管理工具

SysNet 是一个基于现代反向代理内核打造的自动化内网穿透管理脚本。支持服务端与客户端一键安装配置、多环境守护支持（Systemd / Supervisord / Nohup）、进程名与目录隐蔽伪装，以及敏感配置安全防护。

---

## ⚡ 一键安装运行

在终端中以 `root` 权限执行以下命令即可启动交互式管理菜单：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/alienmoom/sysnet/main/sysnet.sh)
```

> **提示**：若在国内网络环境下访问 GitHub 较慢，可以使用加速节点：
> ```bash
> bash <(curl -fsSL https://ghproxy.net/https://raw.githubusercontent.com/alienmoom/sysnet/main/sysnet.sh)
> ```

---

## ✨ 核心特性

- 🔒 **隐蔽与防探测**：
  - 安装路径采用系统隐藏目录 `/usr/local/share/.sysnet`（`chmod 700`）。
  - 进程与二进制重命名为 `sysnet-srv` / `sysnet-agent`，系统进程列表（`ps`/`top`）中不出现任何敏感特征。
  - 随机化代理标识，避免在服务端暴露内网真实主机名（Hostname）。
- 🛡️ **安全权限加固**：
  - 配置文件与认证凭据强制设置为 `chmod 600`，仅 root 可读写。
- ⚙️ **默认端口映射优化**：
  - 本地 SSH（22）端口 ➜ 远程默认映射至 **7322**。
  - 本地 HTTPS（443）端口 ➜ 远程默认映射至 **7323**。
- 🔄 **全环境自启守护**：
  - 自动识别并适配 `systemd` 与 `supervisord` / `nohup` 环境（完美兼容容器化与轻量系统）。
- 📦 **管理便捷**：
  - 支持交互式配置输入、状态查看与一键彻底卸载。

## 📖 使用指南

1. **服务端部署（公网云服务器）**：
   - 运行脚本选择 `1. 安装服务端`。
   - 输入通信端口（默认 7000）、认证 Token 以及 Web 管理面板端口（默认 7500）。
   - 确保安全组/防火墙开放对应端口。

2. **客户端部署（内网服务器/本地机器）**：
   - 运行脚本选择 `2. 安装客户端`。
   - 输入中继服务器公网 IP、通信端口、认证 Token。
   - 确认 SSH（22 -> 7322）和 HTTPS（443 -> 7323）远程端口映射。

3. **查看配置与状态**：
   - 运行脚本选择 `3. 显示当前配置信息`。

4. **卸载清理**：
   - 运行脚本选择 `4. 卸载服务`，自动停止进程、清理服务与安装文件。
