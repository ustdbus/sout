## 核心特性

- 🎯 **s-ui 原生深度适配**：专为 `s-ui` 面板（sing-box 内核）打造，直接对接 SQLite 数据库与路由引擎，配置秒级热重载。
- ⚡ **单端口多用户智能分流（0 额外端口占用）**：
  - 彻底废除多端口克隆机制，所有家宽分流与原生直连节点 100% 共享母机入站端口（如 REALITY、VMess-WS 等）。
  - 分流节点与母节点完全共用网络传输参数（REALITY PBK/SNI、CDN 优选 IP 列表等），仅分配独立 Client UUID。
  - 通过 sing-box 原生 `auth_user` 路由规则精准定向至指定的家宽 OpenVPN 出口隧道。
- 🌐 **VPN Gate 全球家宽出口池**：
  - 全自动拉取并解析 VPN Gate 公共家宽节点。
  - 具备延迟、带宽实时探测，支持槽位锁定与节点动态恢复。
- 📦 **完整订阅接口（`/sub`）**：
  - 自动生成专属订阅链接，代理客户端请求默认返回标准 Base64，浏览器访问返回直观明文。
  - 顶部一键导出全部原生直连与家宽分流节点。
- 🔒 **反向代理与面板 URL 自定义**：
  - 支持一键切换 `127.0.0.1` 仅本地监听，便于 Nginx / 1Panel / Caddy 等反向代理。
  - 支持自定义「面板 URL」，终端管理菜单与展示信息自动同步。
- 🛠️ **极简终端运维命令**：
  - 在终端输入 `sout` 或 `f` 即可呼出交互式控制台，支持管理端口、口令、路径重置、开机自启及一键干净卸载。

## 一键安装

在 Linux 服务器（Ubuntu / Debian / CentOS / Alpine 等）上执行：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ustdbus/sout/main/install.sh)
```

---

## 快捷管理

安装完成后，在终端直接输入 `sout` 或 `f` 即可呼出交互式控制台：

```bash
sout
# 或者
f
```

## 卸载与清理

如需卸载，在终端输入 `sout` 选择 `13`，或执行：

```bash
sout uninstall
```
> 卸载程序会自动清理由插件生成的所有 OpenVPN 网络命名空间、虚拟网卡，并自动从 s-ui 数据库中移除由插件创建的出口出站、路由规则与分流用户，完全恢复 s-ui 的原始纯净状态。
